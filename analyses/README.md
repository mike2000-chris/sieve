# Analyses

One folder per executed card: `analyses/SIEVE-XXXX/` with `queries/` (text files, archive-side), `run.py` or notebooks,
`environment.lock` (uv export), and `results/` (small tables only). Raw data never enter the repository (see `.gitignore`).

`analyses/dr4-day-one/` holds the pre-registered Gaia DR4 queries prepared before 2 December 2026 (Phase 0 task).
